隐私政策

本政策适用于 Awin Sync Personal 当前提供的 Awin 转化数据同步功能。

访问的数据及用途

脚本通过 Awin API 获取转化记录，并将同步结果写入配置的 Google Sheets 表格，用于查看和核对。脚本在写入目标表格时使用 Google 授权。实际请求的权限以 Google 授权页面所列内容为准。

数据传输与存储

当前同步流程在 Google Apps Script 中运行。同步结果存放在目标 Google 表格中，其访问范围由该表格的共享设置决定。当前流程将 Awin 转化数据写入 Google Sheets，不会把同步数据发送给 Google Ads 或其他外部服务。

管理授权与删除数据

你可以停止同步，并在 Google 账号的第三方连接页面管理或撤销授权。撤销授权会阻止脚本继续使用该授权，之前写入的记录仍在表格中。你可以在有编辑权限时删除已同步的行，或通过下方邮箱联系运营者处理删除请求。

后续功能与政策更新

如果启用 Google Ads 转化回传，本政策将更新，说明实际发送的数据、接收服务、用途和管理方式。新增权限会在启用相关功能前请求。

Awin Sync Personal 对通过 Google API 获取的信息的使用和转移遵循 Google API Services User Data Policy 的有限使用要求。
